# VRS.Details — Public Issue Tracker

Этот репозиторий предназначен только для сообщений об ошибках,
предложений и запросов по программе VRS.Details.

## Сообщить об ошибке

Откройте вкладку Issues и создайте новый Issue.

Перед созданием укажите:

- версию VRS.Details;
- что вы делали;
- ожидаемый результат;
- фактический результат;
- текст ошибки;
- скриншоты, если они есть.

## Предложить улучшение

Создайте Issue с типом Feature Request.
